点 main_guide 后必须确认真的进了指南, 否则重试

用户日志实证(2026-10-14 13:41):
  已点击 main_guide (1245, 803)          <- 报了"已点击"
  但之后所有 OCR 结果都是**主页面**内容:
    活动 / 排行榜 / 积分赛 / 奖励 / 丰饶之间 / 任务集 / 忍界指引 / 组织 / 决斗场 ...
  说明界面根本没换 —— 后面"往下找 1/20..5/20"全是在滚动**主页面左侧那一列图标**
  (所以画面差异照样在变、日志看起来一切正常), 自然永远找不到「小队突袭」。

修法(用户提出的判据): 新增 GuideNavTask.open_guide()
  * 点 main_guide -> 等 GUIDE_ENTRY_VERIFY_WAIT = 1.0 秒
  * 如果**还能看到 main_guide**(进了指南界面就看不到它了) -> 判定"还停在主页面"
    -> 记 warning 并重试, 最多 GUIDE_ENTRY_ATTEMPTS = 3 次
  * 确认进去了才继续; 连续失败直接 return False, 不再让后续步骤白跑
  * enter_guide 改走 open_guide(), 不再自己裸点(否则绕过确认)

这类"没进去但后面照跑"的失败以前要到很后面才暴露(甚至不暴露),
现在在**最外层第一步**就被发现并重试。
